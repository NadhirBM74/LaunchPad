# 🚀 LaunchPad pour macOS

Une réinvention moderne, fluide et personnalisable du Launchpad pour macOS, développée nativement en Swift et SwiftUI.

## ✨ Fonctionnalités

- 🪟 **Interface Liquid Glass** : Arrière-plan flouté moderne inspiré du design macOS.
- ⚡ **Raccourcis & Gestes** : Activation par raccourci clavier personnalisable, pincement trackpad (3 ou 4 doigts) ou coin actif (Hot Corners).
- 🧩 **Widgets intégrés** : Horloge, statistiques système en direct (CPU/RAM), notes rapides et contrôle multimédia (Apple Music & Spotify).
- 🔒 **Dossiers sécurisés Touch ID** : Verrouillez vos dossiers sensibles avec l'authentification biométrique native du Mac.
- ⭐ **Barre de favoris & Tuiles personnalisées** : Épinglez vos applications et créez des tuiles directes vers vos dossiers ou sites favoris.
- 🔄 **Mise à jour automatique en 1 clic** :
  - Détection automatique des nouvelles versions via l'API GitHub Releases.
  - Notifications macOS natives.
  - Téléchargement, installation silencieuse et redémarrage automatique dans l'onglet *Réglages › À propos*.

## 🛠️ Compilation depuis les sources

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/NadhirBM74/LaunchPad.git
   cd LaunchPad
   ```
2. Ouvrez le projet dans Xcode :
   ```bash
   open LaunchPad.xcodeproj
   ```
3. Compilez (`Cmd + B`) ou exécutez (`Cmd + R`).
